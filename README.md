# SQLi Interactive Lab - Proiect de Licență

## Descriere
Acest proiect este o aplicație web interactivă dezvoltată pentru a demonstra și analiza vulnerabilitățile de tip SQL Injection (SQLi). Scopul principal este strict educațional, oferind un mediu practic pentru înțelegerea vectorilor de atac asupra aplicațiilor web și implementarea mecanismelor de apărare. Proiectul a fost realizat ca parte a lucrării de licență.

## Funcționalități
* **Simulare de Atacuri:** Un mediu controlat pentru testarea practică a diferitelor tehnici de SQL Injection.
* **Analiză de Securitate:** Explicații aplicate despre modul în care interogările malițioase interacționează cu baza de date.
* **Arhitectură de Bază:** Demonstrarea diferențelor dintre interogările vulnerabile și cele securizate.

## Tehnologii Folosite
* **Bază de Date:** SQLite (pentru gestionarea eficientă a structurilor relaționale și a datelor aplicației).
* **Mediu de Rulare:** Aplicația poate fi rulată local sau izolată într-o mașină virtuală (cum ar fi Linux Mint).
* **Arhitectură:** Client-Server.
